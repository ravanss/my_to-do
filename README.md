# my_to-do
Web app para gerenciamento de tarefas do dia-a-dia.
<hr/>
<h1>Resumo</h1>
<p>Projeto webApp de gerenciamento de tarefas com funcionalidades:</p>
</br>
<ul>
    <li>
        Criação de conta de usuario
    </li>
    <li>
        Login no sistema ao sistema
    </li>
    <li>
        Recuperação de senha pelo sistema
    </li>
    <li>
        Funcionalidades de criação, deleção, alteração e conclusão das tarefas
    </li>
</ul>
<hr/>
<h2>O sistema</h2>
<p>O sistema foi desenvolvido com o intuito de disponibilizar uma maneira de geraciar tarefa do dia-a-dia apartir de uma simples pagina web.</p>
